A lightweight and modular operating system built with [**Cosmos Gen3**](https://github.com/valentinbreiz/nativeaot-patcher) using the Native AOT Patcher. VoidOS has changed from a GUI environment into a CLI based, server-oriented OS. Basically im trying to run SSH Server on Cosmos 😅
